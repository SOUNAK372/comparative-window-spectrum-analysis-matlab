# Comparative Window Spectrum Analysis using MATLAB

## Overview

This project presents a comparative frequency-domain analysis of four widely used digital window functions:

- Rectangular Window
- Hanning Window
- Hamming Window
- Blackman Window

The MATLAB implementation visualizes both the magnitude and phase responses of each window and compares their spectral characteristics to study frequency resolution and spectral leakage.

---

## Features

- MATLAB implementation compatible with MATLAB R2013
- Frequency spectrum analysis of four window functions
- Magnitude and phase response visualization
- Comparative spectrum analysis
- Automatic generation of output figures
